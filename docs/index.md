Oh My Otter checks how ready a repository is for coding agents and lets you run standardized benchmark tasks locally.

## Get started

- [Quickstart](./quickstart.md) — install the CLI and run your first scan.
- [CLI reference](./cli.md) — scan, list checks, run benchmarks, and report results.
- [CI usage](./ci.md) — set a minimum readiness score in continuous integration.

## Guides

- [Plugins](./plugins.md) — load trusted custom checks.
- [Scoring](./scoring.md) — understand readiness scores and grades.
- [Writing a check](./writing-a-check.md) — author a repository-readiness check.
- [Writing a benchmark task](./writing-a-task.md) — add a benchmark task and its documentation.

Benchmark tasks: [add-unit-test](./benchmarks/add-unit-test.md), [dep-patch-bump](./benchmarks/dep-patch-bump.md), [fix-lint-rule](./benchmarks/fix-lint-rule.md), [a11y-img-alt](./benchmarks/a11y-img-alt.md), [ts-strict-file](./benchmarks/ts-strict-file.md), and [fix-failing-test](./benchmarks/fix-failing-test.md).
