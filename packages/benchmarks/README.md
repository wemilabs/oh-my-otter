# @oh-my-otter/benchmarks

Standardized benchmark tasks and local verifiers for AI coding agents, used by `omot bench`.
Run tasks with the [oh-my-otter CLI](https://www.npmjs.com/package/oh-my-otter).
This is a private workspace package: it's bundled into the CLI and isn't published to npm.
Repository: https://github.com/wemilabs/oh-my-otter
Unofficial and independent; not affiliated with or endorsed by Cognition or any other agent vendor.
